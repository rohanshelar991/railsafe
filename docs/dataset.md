# Dataset and video provenance

The original README describes a controlled custom environment captured with track and train models. It does not provide a dataset card, license statement, train/validation/test split, class distribution, or ground-truth distance/tracking labels. Therefore this project does not claim to have trained or evaluated a new model on it.

The upstream video inventory is: `complex1.mp4` through `complex7.mp4`, `complex_crash.mp4`, `complex_left.mp4`, `complex_right.mp4`, `normal_left.mp4`, and `normal_right.mp4`. `complex_crash.mp4` was successfully opened locally: 1920×1080, 30 FPS, 268 frames, 8.93 s.

No external dataset has been downloaded or used. Before a training experiment, record license, acquisition, annotations, scene-level train/validation/test splitting, class balance, and preprocessing in this document.
